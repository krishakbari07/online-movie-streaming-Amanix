**How to run the Online Movies Streaming Platform Project Using Python with django and MySQL**



1.Open PHPMyAdmin (http://localhost/phpmyadmin)

2.Create a database with name 'amanix'

3.Import amanix.sql file

4.Open VS code -> Open Folder -> select the 'amanix'

5.Open Terminal, Run this following commands 
	-> install pip
	-> cd myvnev
	-> ./Scripts/activate
	-> cd ..
	-> py manage.py runserver

6. 'http://127.0.0.1:8000/' ctrl+Left Click on this link
